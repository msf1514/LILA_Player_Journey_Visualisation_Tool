# LILA BLACK player journey visualisation tool

Live tool: https://lila-pjvt.msf1514.workers.dev

A browser-based tool for exploring LILA BLACK match telemetry: player traffic, dwell,
loot, kills, deaths, journeys, hotspots and day-to-day change, across every map.
